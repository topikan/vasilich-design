# VASILICH DESIGN — дизайн-референс сайта

Живой макет сайта студии 3D-визуализации: 10 блоков по ТЗ, от шапки до подвала.

## Структура

- `site/index.html` — макет сайта (открыть в браузере)
- `site/spec.html` — дизайн-система: логотип, палитра, шрифты, UI-элементы, состояния, анимации, адаптив
- `site/styles.css` — общие стили и токены
- `site/assets/` — рендеры, сжатые для веба, и 3D-модель куба (`cube.glb`)
- `renders/` — исходные рендеры
- `ТЗ.txt` — техническое задание

## Просмотр

Модель куба загружается через fetch, поэтому страницу нужно открывать через локальный сервер, а не двойным кликом:

```
cd site
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

## Шрифты

Unbounded (заголовки) и Golos Text (текст), Google Fonts.
